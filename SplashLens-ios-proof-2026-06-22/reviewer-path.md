# App Review Path - June 22, 2026

## Review Notes Summary

SplashLens is a free utility/reference wrapper around the SplashLens PWA at:

`https://app.splashlens.com/?store=ios`

No account is required for core use. Manual lookup, Route Brain planning, calculators, notes, filters, and checklists work from the app shell after first load. PartSnap is an optional online scanner mode for pool part reference assistance. Camera/photo access is user-initiated and only used for optional AI scanner workflows. Microphone access is user-initiated for dictated service notes where the webview/browser supports speech recognition. Online AI scan features require internet access. PartSnap results are possible matches with missing-proof prompts and verification language, not confirmed part-fit results.

Store wrapper mode is intended to stay free-core and must not show direct Stripe checkout or web-subscription CTAs. AI scan output is assistance only and should be verified against equipment manuals, calibrated tests, label directions, and professional field judgment.

This build does not include native paid entitlements, unlimited AI scanning, completed training certificates, manufacturer endorsement, sponsored manufacturer placements, or guaranteed diagnosis claims.

## Suggested Reviewer Steps

1. Open the app.
2. Confirm the first screen says "Find the part. Fix the stop."
3. Tap "PartSnap Parts ID".
4. Start scanner mode.
5. Allow camera access only when prompted.
6. Capture a part/label image, or observe scanner guidance if using a simulator.
7. Confirm the result uses possible-match or missing-proof language and tells the user to verify before ordering.
8. Confirm the escalation/missing-proof packet can be copied.
9. Open manual lookup and search `E05`.
10. Open dosing calculator and confirm field calculator controls render.
11. Open service note/report and Route Brain to confirm the other field tools render.

## Reviewer Caveat

If review uses the simulator camera test feed, PartSnap may return a low-confidence or unidentified result. That is expected and is consistent with the app's conservative reference-assistance posture.
